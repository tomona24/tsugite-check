# 継手チェック（GitHub Pages 版）

このフォルダの中身をそのまま GitHub Pages に置くと、iPad・Android の Chrome からアプリとして使えます。
記録は各端末の中にだけ保存されます（サーバには何も送りません）。様式のExcelはサイトに含めず、別ファイル「様式パック.jctpl」を各端末で読み込みます。

版: 20261028-619f048f

## 1. 初回の公開（GitHub の画面だけで行います）

1. GitHub にサインインし、右上の「＋」→「New repository」。
2. Repository name に好きな名前（例: `joint-check`）を入れ、**Public** を選んで「Create repository」。
3. できたリポジトリの画面で「Add file」→「Upload files」。
4. このフォルダの中身（`index.html`・`sw.js`・`manifest.webmanifest`・`icons` フォルダ・この `README.md`）をまとめてドラッグ＆ドロップし、「Commit changes」。
   ※ `icons` はフォルダごと入れてください（`icons/icon-192.png`・`icons/icon-512.png`）。
   ※ **様式パック.jctpl はアップロードしないでください**（公開サイトには置きません）。
5. リポジトリの「Settings」→ 左の「Pages」。
6. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main** ／ **/ (root)** にして「Save」。
7. 1〜2分待つと、同じ画面の上部にアドレスが出ます。形は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## 2. 各端末での準備（iPad・Android とも Chrome で）

1. Chrome で上のアドレスを開く。
2. Chrome のメニュー（︙）→「ホーム画面に追加」（iPad では「アプリをインストール」や共有ボタン→「ホーム画面に追加」）。
3. ホーム画面のアイコンから開く。最初に「様式パックを読み込む」画面が出るので、Google ドライブ等に置いた **様式パック.jctpl** を選ぶ。
4. 以後はオフラインでも使えます（一度開いた後はネットがなくても起動します）。

## 3. 端末の間で記録を合わせる

- ホームの「書き出す」で全ての記録を1つのファイル（JSON）にし、Google ドライブなどに保存します。
- もう一方の端末でホームの「取り込む」からそのファイルを選ぶと、記録が合わさります（取り込みで記録が消えることはありません。取り込む前の状態はアプリ内に3件まで残り、「設定・バックアップ」から戻せます）。
- 変更したあと書き出していないと、ホームと工事の画面に案内が出ます。

## 4. アプリを更新するとき

1. 新しい `index.html`・`sw.js`・`manifest.webmanifest`（必要なら `icons`）を、リポジトリの「Add file」→「Upload files」で同じ名前のまま上書きして「Commit changes」。
2. 各端末でアプリを開くと、しばらくして画面の下に「新しい版があります 再読み込み」と出るので押します（出ないときは一度閉じて開き直してください）。
3. 様式パックも新しくなったときは、「判定基準・様式ファイルの管理」→「様式パックを読み込み直す」で新しい `様式パック.jctpl` を読み込みます。

## 5. 注意

- GitHub Pages の公開サイトは誰でも開けますが、記録はサイトには送られません。記録のファイル（JSON）は Google ドライブ等の自分の場所に置いてください。
- 長く使わない端末では、ブラウザがデータを消すことがあります。こまめに「書き出す」を押してください。
